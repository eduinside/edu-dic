# 어린이 쉬운 사전

유치원~초등 저학년이 (교사 지도 또는 스스로) 어려운 낱말을 입력하면 **쉬운 뜻풀이 + 그림 1장**을 큰 화면으로 보여 주는 사전 앱. 수업 시간 투사가 1순위 사용 맥락.

- 계획서: [`docs/PLAN.md`](docs/PLAN.md)
- 정본 도메인: `dic.dgedu.link`
- 스택: Vite + React + Tailwind v4 + Cloudflare Pages/Functions + D1(공유 `edu-link-db`)

## 개발

```bash
npm install
npm run dev            # vite (프런트만) — http://localhost:5173
```

Functions(`/api/*`)까지 함께 테스트하려면:

```bash
npm run build          # dist 생성
npm run pages:dev      # wrangler pages dev — Functions + 정적 자산
```

## 인증키

```bash
cp .dev.vars.example .dev.vars   # 그리고 값 채우기
```

| 변수 | 필수 | 용도 |
|---|---|---|
| `KRDICT_API_KEY` | 필수 | 국립국어원 한국어기초사전 오픈 API — 사전 텍스트·이미지·소리 1차 소스 |
| `ENCYKOREA_API_KEY` | 선택 | 한국민족문화대백과사전 — krdict 미수록 텍스트, 또는 krdict에 이미지 없을 때 2차 이미지 소스 |
| `X-NCP-APIGW-API-KEY-ID` / `X-NCP-APIGW-API-KEY` | 선택 | 네이버 이미지 검색(NCP API Gateway) — krdict·encykorea 둘 다 이미지 없을 때 3차 폴백 |
| `TIMELY_API_KEY` | 선택 | AI 게이트웨이 — 오타 교정·쉬운 말 변환·관련어 제안(3종 모두 이 키로 동작) |
| `GEMINI_API_KEY` | 선택 | Timely 실패 시 직접 폴백(보통 안 넣어도 됨) |

선택값은 모두 없어도 앱이 정상 동작한다(해당 기능만 조용히 생략). 로컬은 `.dev.vars`(gitignore됨), 운영은 `wrangler pages secret put <이름>` 또는 CF 대시보드 환경변수.

## D1 테이블 적용(공유 DB, 멱등)

```bash
npm run db:local       # 로컬 D1에 edudic_ 테이블 생성
npm run db:remote      # 운영 D1(edu-link-db)에 적용
```

> D1은 신규 생성하지 않고 `edu-link-db`를 공유한다. edu-dic 테이블은 모두 `edudic_` 접두어(계획서 D12). `CREATE TABLE IF NOT EXISTS`로 멱등 적용해 edu-link 마이그레이션과 충돌하지 않는다.

## 현재 상태 (M1)

**홈**
- 중앙 대형 검색창(자동 포커스) + 검색창 아래 **4열**(내가 찾은 | 즐겨찾기한 | 자주 찾는 | 추천, 각 최대 8개, 화면 전체 폭)
- 정렬: 내가 찾은=최근 검색순, 즐겨찾기=등록 역순, **자주 찾는=최근 30일 다른 사용자 합산**(전역), 추천=시스템 큐레이션
- 답을 못 찾은 검색어는 기록에 남지 않음

**나의 낱말사전** (`/my` 전용 URL)
- 좌: 나의 활동(탭 — 내가 찾은 · 즐겨찾기 한 · **내가 자주 찾은**[전체기간, 개인 로컬 집계]), 배지 목록
- 우: 낱말 익히기(주제 카드, 클릭 시 펼쳐서 전체 낱말 노출) + 수준·관심주제 설정(모달)

**검색 결과**
- `/api/lookup` — 금칙어 프리필터 → D1 캐시 → krdict 검색+상세 정규화 → 캐시 저장, `/api/popular` — 인기 낱말 집계(최근 30일)
- 텍스트·이미지 소스 우선순위: **krdict → (텍스트만) encykorea 대체 / (이미지만) encykorea → 네이버** — 화면에 소스별로 다른 출처 표시. 이미지가 전혀 없으면 자리를 비움(가짜 타일 없음)
- **동음이의어**(예: "배"=신체/선박/과일 등) 전환 탭 — 뜻마다 이미지·소리·쉬운말 변환이 독립적으로 동작. 이미지 검색은 뜻풀이에서 뽑은 힌트로 동음이의어를 반영하되, 힌트가 너무 일반적이면(오검색 위험) 이미지 생략
- 발음 소리 재생 버튼(krdict, CC BY-NC-ND — 이미지 라이선스와 다름)
- 검색 결과를 **`/낱말`** 경로로 그대로 공유 가능(재방문 시 자동 재현, 과거 `?q=` 링크도 지원)
- 결과 아래 같은 낱말 세트의 "관련 낱말 더 보기" + AI가 제안하는 "비슷한 낱말"
- 상단 "사전 그대로 / 쉬운 말로" 토글(결과 화면에서만 노출, 헤더 높이 고정) — AI가 뜻풀이를 초등 저학년 눈높이로 **명사형 종결**로 재설명(사실 추가 없이, 동음이의어 탭별 독립 캐시)
- "큰 화면(발표)" 모드: 전체 폭 + 카드가 화면 높이 약 70% + 낱말·뜻풀이·이미지 확대(교실 투사용), 전환 시 토스트 알림
- 모바일에서 이미지는 카드 전체 폭 사용, `object-contain`으로 크롭 없이 원본 비율 유지

**AI(Timely 게이트웨이)** — 키 없으면 조용히 생략
- 오타 교정: AI 후보를 krdict로 재검증한 것만 제안
- 쉬운 말 변환: 사전 뜻풀이를 뼈대로 새 사실 추가 없이 재설명, 명사형 종결
- 관련어 제안: AI 후보 중 krdict에 실존하는 낱말만 노출
