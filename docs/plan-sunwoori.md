### 1.1 저작권 판단 → "목록은 쓰고, 소개말은 원문으로 보낸다"

- **낱말 이름(표제어)과 글번호**는 사실 정보라 목록으로 써도 무리가 없다. 화면에 '낱말 목록 출처: 충북교육문화원 한글사랑관'을 밝히고 낱말마다 **원문 소개 글 링크**를 단다.

- 원 기관에 따로 연락하지 않는다(운영자 결정 §7-2). 목록만 참조하고 출처 표시와 원문 링크를 남긴다. 소개말 본문은 끝까지 싣지 않는다.

## 2. 막히는 지점 — D10(미수록 낱말 차단)

지금 사전은 **기초사전에 없는 낱말을 '준비 중'으로 막는다**(D10, 안전 우선). 순우리말은 기초사전 밖 낱말이 많아(§1 표) 그대로 붙이면 목록에서 눌러도 상당수가 '준비 중'으로 나온다.

**결정(D28): D10을 '목록 안 낱말'에 한해 푼다.**
- 순우리말 목록(교사가 검수한 닫힌 목록)에 있는 낱말만, 기초사전에 없으면 **표준국어대사전 오픈 API**로 뜻을 가져온다. 표준대사전에도 없는 낱말은 목록에서 뺀다.
- 일반 검색창에 아무 낱말이나 쳤을 때의 동작(D10 차단)은 그대로 둔다 → 안전 원칙 유지.
- 표준대사전 뜻은 어른 눈높이라 기본 보기를 **'쉬운 말로'**로 열고, 출처 표시를 '표준국어대사전'으로 바꾼다(D20 encykorea 대체 때와 같은 방식).
- 새 키(표준국어대사전 오픈 API, 무료) 1개 필요. 뜻풀이 이용 조건은 키 발급 때 확인해 화면 출처 표시와 README 라이선스 표에 적는다. `.dev.vars`·Pages 비밀값에 추가, 키관리.exe에 등록.

## 3. 화면 배치 — 지금 화면은 그대로, 들어가는 문 3개

첫 화면(검색창 + 4열)과 결과 화면 구조는 바꾸지 않는다. 순우리말은 **별도 페이지**로 두고, 기존 화면에는 작은 문만 단다.

| 들어가는 문 | 위치 | 바뀌는 정도 |
|---|---|---|
| ① 머리말 단추 '순우리말' | 상단 머리말, '나의 낱말사전' 옆(모바일은 아이콘만) | 단추 1개 |
| ⓪ 첫 화면 '추천 낱말' 열 한 줄 | 열 맨 위에 `🌱 이달의 순우리말: 간들거리다` 한 줄(누르면 그 낱말 결과, 옆 '더 보기'는 `/uri`). 4열 배치·개수는 그대로, 추천 낱말이 1개 줄어듦 | 줄 1개 |
| ② 결과 화면 배지 | 찾은 낱말이 목록에 있으면 낱말 옆에 `순우리말` 배지 + 아래 칩 줄 `[순우리말] 낱말 더 보기`(기존 D15 '관련 낱말 더 보기' 칩 재사용) | 기존 칩 줄 1개 추가 |
| ③ 나의 낱말사전 주제 카드 | '낱말 익히기' 기본 주제에 `🌱 이달의 순우리말` 카드 1장(관심 주제 모달에서 끌 수 있음) | 카드 1장 |

> 첫 화면 4열의 배치는 손대지 않는다. ⓪ 한 줄은 '추천 낱말' 열 안에서만 바뀐다(§7-4).

### 3.1 순우리말 페이지 `/uri`

경로를 한글(`/순우리말`)로 두면 낱말 검색 경로(D18 `/낱말`)와 겹쳐서 '순우리말'이라는 낱말 검색이 된다. `/my`처럼 **영문 예약 경로 `/uri`**를 쓴다.

```
┌──────────────────────────────────────────────┐
│ 🌱 순우리말 배움터                              │
│ ┌ 이달의 순우리말 ────────────────────────┐    │
│ │  간들거리다   [뜻 보기] [원문 소개 글 ↗]   │    │  ← 가장 최근 글
│ └────────────────────────────────────────┘    │
│ [ 목록 안에서 찾기 (초성도 돼요) ]              │
│ 쉬운 낱말 | 모든 낱말        ㄱ ㄴ ㄷ ㄹ ㅁ ㅂ … │  ← 난이도 + 첫 글자
│ 갈래: 마음·느낌 | 몸짓·모양 | 날씨·자연 | 사람 | 살림 │
│ ┌────────┐ ┌────────┐ ┌────────┐              │
│ │ 윤슬  ☐ │ │ 출출하다☐│ │ 고뿔  ☐ │  …          │  ← 낱말 + 짧은 뜻 + 담기 상자
│ │ 햇빛에…│ │ …       │ │ …       │              │
│ └────────┘ └────────┘ └────────┘              │
│ 낱말 목록 출처: 충북교육문화원 한글사랑관 · 뜻풀이: 국립국어원 │
└──────────────────────────────────────────────┘
  ▼ 하나라도 고르면 아래에 떠 있는 줄
  [ 3개 골랐어요   낱말장 만들기 · 내 낱말장에 넣기 ]
```

- **찾기**: 목록 안 검색(기존 초성 매칭 `matchesChoseongOrPrefix` 재사용) + 첫 글자 칩 + 갈래 칩.
- **난이도**: 기본은 '쉬운 낱말'(기초사전 수록어). '모든 낱말'로 바꾸면 표준대사전 낱말까지.
- **갈래**: S5로 미룬다(§7-5). 그때 663개를 5~6갈래로 나눠 데이터에 넣는다(AI 초벌 → 운영자 검수). 갈래 이름은 화면 글투 기준(CLAUDE.md)에 맞춰 일상어로. 처음 공개 때 위 그림의 갈래 줄은 빠진다.
- **카드 누르기** → 기존 결과 화면(`/낱말`)으로 이동. 그림·소리·쉬운 말·즐겨찾기가 그대로 동작한다.
- 목록 데이터는 이 페이지에서만 늦게 불러온다(dynamic import) → 첫 화면 속도(설계 원칙 ★)에 영향 없음.

## 4. 낱말장 — 기존 '내가 만든 주제'를 그대로 쓴다

낱말장 = 이미 있는 `CustomWordSet`(localStorage `edudic.customTopics`) + 공유(`/api/share-topic` → dgedu.link 단축 주소). 새 저장소나 로그인이 필요 없다.

| 할 일 | 방식 |
|---|---|
| 만들기 | 순우리말 페이지에서 상자 체크 → '낱말장 만들기' → 이름·이모지 입력 → `CustomWordSet` 저장(`source: "uri"` 표시만 추가) |
| 더 넣기 | '내 낱말장에 넣기' → 기존 낱말장 고르기 → 낱말 합치기(겹침 제거) |
| 보기·익히기 | 나의 낱말사전 '낱말 익히기'에 `직접 만듦` 카드로 나타남(현행 그대로) |
| 나누기 | 카드의 '공유' → dgedu.link 단축 주소 → 받은 학생 기기에 `공유 받음` 카드로(현행 그대로) |
| 결과 화면에서 담기 | (2단계) 결과 화면 별표 옆 '낱말장에 담기' — 순우리말이 아닌 낱말도 담을 수 있게 |
| 인쇄 | (2단계) 낱말장을 A4 한 장 유인물로(낱말·뜻·빈 예문 줄) |
| 카드 익히기 | (2단계) 뜻 가리고 넘기며 맞혀 보기 |

> 학생이 만든 낱말장은 기기 안에만 있다(D6). 다른 기기에서 이어 쓰려면 공유 주소로 옮긴다. 공유 시 낱말장 이름은 금칙어 필터(D8)를 통과해야 한다 — **지금 `/api/share-topic`은 이름·낱말을 검사하지 않는다**(검사는 `/api/topic-words`에만 있음). 학생이 직접 이름을 짓게 되므로 S2에서 `isBlocked` 검사를 공유 API에 넣는다.

## 5. 데이터 만들기

- `scripts/sunwoori-sync.mjs`(새로 작성): 게시판 목록 43쪽을 읽어 `글번호·제목·등록일` → 낱말 분리 → 국어원 사전으로 수록 여부·품사·등급·짧은 뜻 확인 → `app/data/sunwoori.json`.
  - 항목(구현): `{ w, no, d, pos, kr, g }` — 낱말·글번호·날짜·표준대사전 품사·기초사전 수록 여부(null=확인 못 함)·어휘 등급. 뜻은 넣지 않는다.
  - 사전 어디에도 없는 낱말(`source: null`)은 목록에서 뺀다(뜻을 보여 줄 수 없으므로).
  - 같은 낱말이 여러 글에 있으면 가장 최근 글번호 하나만.
- 갱신: 매달 새 글이 1개씩 올라오므로 **달마다 스크립트를 한 번 돌려 커밋**(main 푸시 = 배포). 자동 수집 Worker는 두지 않는다(무료 티어·단순함 유지).
- 캐시 미리 채우기: 목록 낱말을 한 번씩 `/api/lookup`으로 불러 D1 `edudic_dict_cache`를 채워 두면 학생이 누를 때 바로 뜬다(D5 시드 워밍과 같은 방식).
- 크기: 600여 낱말 × 약 100바이트 ≈ 60KB(압축 시 20KB 안팎), `/uri`에서만 받음.

## 7. 운영자 결정 (2026-11-02)

1. **미수록 낱말** — 목록 안 순우리말에 한해 **표준국어대사전** 뜻을 보여 준다(D28). 일반 검색창은 D10 그대로 '준비 중'. 우리말샘은 쓰지 않는다.
2. **원 기관** — 연락하지 않는다. **목록만 참조하고 출처 표시·원문 링크를 남긴다.** 소개말·예문은 싣지 않는다.
3. **페이지 이름·경로** — 따로 정하지 않아 기본안 '순우리말 배움터'(`/uri`)로 간다. 구현 때 바꿀 수 있다.
4. **첫 화면** — 머리말 단추에 더해 **'추천 낱말' 열 맨 위에 '이달의 순우리말' 한 줄**을 넣는다(§3 ⓪).
5. **갈래** — **나중에**(S5). S1은 초성 검색·첫 글자·쉬운/모든 낱말로 시작.
